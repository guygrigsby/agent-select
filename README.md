# Agent routing

Research artifact for a future local Go subagent routing library. No router or collection service is implemented. A CLI is a proposed thin testing/early integration adapter that invokes the same Go public API.

Open `data/research.sqlite` for captured catalogs, provider prices, model claims, benchmark measurements, unresolved model labels, source hashes and coverage gaps. Vercel is the baseline; models.dev is cross-referenced by exact offer ID. `make check` validates artifact integrity, evidence hashes and catalog coverage, not model quality.

Catalog-source research and selected published-measurement provenance passed review. `evidence_reviews`, `source_validated_benchmarks` and `source_validated_unresolved` identify source-checked values separately from routing eligibility. `review_results` still quarantines characteristic/quality admission and `accepted_benchmarks` is empty. Historical labels, unknown evaluation settings and current-alias identity remain explicit. Claims without saved evidence are isolated in `unlocated_claims`. Missing scores do not establish weakness. Raw pricing paths preserve source dimensions; `source_specific_unresolved` units cannot be used for cost admission.

`data/source-manifest.tsv` records byte hashes and recoverable URLs. File timestamps are labelled local mtime, not asserted HTTP retrieval times. JSON files are interchange/source snapshots, not database JSON columns. Rights remain unknown; keep this material local. The MIT license covers original project material only, not third-party evidence or datasets.

Design drafts live in `docs/specs/`. Start with `collection-pipeline.md`. Image-role limits, temporal identity and benchmark comparability now have dedicated proposed contracts. They have not passed the contract gate: the stale identity-table delegation reference in `ar-yl1` is repaired and a fresh contract review is pending. Full source coverage, current-offer mappings and calibration are not implied by the repairs; remaining coverage is tracked in `ar-orn`. See `docs/research/coverage-followup.md` for the verified GenEval collection source. Do not begin implementation from these drafts.
