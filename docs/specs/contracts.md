# Service, event and data contracts

Authoritative proposed contracts. Superseded for the implemented delivery slice by [delivery storage](delivery-storage.md) under ADR 0003; the delegation targets below remain the owners of their tables. SQL types describe future Postgres authority, not the temporary SQLite research export. Image semantics, identity resolution and benchmark comparability delegate to [image-capabilities](image-capabilities.md), [model-identity](model-identity.md) and [benchmark-comparability](benchmark-comparability.md). Those documents own the matching table names, payloads, events and algorithms. Their classification-only policy records do not enable calibration. The complete classify_measurement and cohort-policy registration contracts are delegated to benchmark-comparability.md; record_attempt accepts its complete typed evidence children.

## Callers and service surface

No public HTTP server is proposed. Embedded Go library methods and collector-internal ports avoid adding an unnecessary network/auth service. A future remote API would require a separate caller/auth contract.

The Go library is the primary boundary for host integrations. A CLI is PROPOSED as a thin testing and early integration adapter that invokes the same public API. Non-Go harnesses may use that process boundary initially; they are not assumed to import Go directly. CLI commands, flags and wire schemas remain unspecified until a later contract pass. The CLI contains no ranking or policy logic. Process startup, decoding and encoding are separate from warm route latency.

Caller classes:

- Host adapter: trusted local invocation from the owning process. May assert its live registry, account eligibility, billing regime and reservations. Cannot assert public benchmark scores, source identity or snapshot integrity. Cannot bypass policy hard constraints.
- Collector worker: OS service identity plus a leased job's fencing token. May submit fetched bytes and deterministic extraction results for its assigned source. Source claims are untrusted until validation; worker cannot publish snapshots or change policy.
- Collector coordinator: owning service identity restricted to enabled sources and declared stages. Includes source-signal consumers, dependency consumers, retry schedulers and lease-recovery workers. External webhooks are authenticated hints where supported, never trusted model facts. Publication-channel retirement belongs to Publisher. Coordinator cannot assert source facts or publish artifacts.
- Publisher: owning service identity with snapshot-store write authority. May publish only a validated artifact. Cannot bless its own failed validation or alter source rights.
- Operator: owning OS user for local source/policy configuration. May set collection scope, rights and spend policy. Cannot relabel a vendor-reported score as independent evidence. Configuration changes are versioned.
- Host outcome reporter: host adapter identity and receipt idempotency key. May assert observed usage and validator outcome. Cannot claim an unknown outcome was independently validated.

Closed error taxonomy: `invalid_request`, `unauthorized`, `forbidden`, `stale_lease`, `conflict`, `source_blocked`, `invalid_evidence`, `identity_unresolved`, `snapshot_unavailable`, `schema_incompatible`, `stale_required_fact`, `no_admissible_offer`, `budget_exceeded` and `temporarily_unavailable`. Errors contain code, safe detail and correlation ID; retry timing is a separate field when applicable. No source bytes or credentials in error text.

Methods, each with complete contract:

- `register_source(Source)` and `revise_source(Source)`: Operator; OS identity; configuration-write authorization. Request is all Source fields from the domain model. Response is source ID and configuration hash. Errors: invalid request, forbidden, conflict. Idempotent by source ID/configuration hash. Invokes `Source.Register` or `RevisePolicy`; disabling invokes `Disable` explicitly through revised enabled state.
- `enqueue_job(source_id, resource_url, stage, input_hash, parser_version)`: Collector coordinator; source must be enabled and allow this use. Response job ID and queued/existing status. Errors: forbidden, source blocked, invalid request. Idempotent by the complete work tuple. Invokes `CollectionJob.Enqueue`. Upstream source-change and retry-deadline signals call this port automatically, not a manual refresh button.
- `lease_job(job_id, worker_id, lease_duration_seconds)`: Collector worker; owning service identity; source/stage assignment authorization. Response includes job fields, fencing token and expiry. Errors: conflict, forbidden, invalid request. Retries return the same active worker lease or conflict; never create two active leases. Invokes `CollectionJob.Lease`.
- `record_attempt(job_id, token, observation, assertions, coverage_findings)`: Collector worker; service identity and active lease token; only its assigned source. Observation/assertion shapes are defined in the domain model; coverage finding is source subject, channel, outcome and detail. Response observation ID, accepted/quarantined assertion counts and durable-output-accepted status. Next work IDs belong to a later completed-job query, never an uncommitted promise. Errors: stale lease, invalid evidence, forbidden, invalid request, temporarily unavailable. Idempotent by full work tuple/output hash/parser version, independent of retried lease token. Invokes `SourceObservation.Record`, committing observation, output link and `StageOutputRecorded` atomically. Its idempotent coordinator consumer invokes `CollectionJob.RecordAttempt` and `Complete` under the current lease. Only durable `JobCompleted` releases dependencies. Crash recovery replays the link/event; a new lease may reuse validated output for the identical work tuple. Expired workers cannot complete. Cannot publish raw proposals as accepted identity facts.
- `defer_job(job_id, token, outcome, detail, retry_not_before)` and `complete_job(job_id, token, output_id)`: Collector worker; active lease; assigned job only. Response durable attempt/completion ID. Errors: stale lease, conflict, invalid request. Idempotent by job/token/transition fingerprint. Invokes `CollectionJob.Defer` or `Complete`. Quarantine is a classified attempt outcome; re-enqueue requires changed source/parser evidence.
- `establish_revision(publisher, revision_name, identity_observation_id, locator)`: Evidence validator under collector service identity; validated exact identity evidence only. Response revision ID. Errors identity_unresolved, invalid_evidence, conflict. Idempotent by identity evidence fingerprint. Invokes ModelRevision.Establish. Binding/confirmation/ending/supersession, policy registration and resolution ports are defined completely in [temporal identity](model-identity.md#service-and-events). They replace the prior un-timed bind_offer and record_alias surfaces. Aliases use the source-scoped ProviderOffer, not a separate temporal algorithm.
- `confirm_offer(offer_fields, observation_id)` and `withdraw_offer(offer_id, observation_id)`: Catalog reconciler under collector service identity; successful schema-valid catalog observations only. Response offer ID/listing fact ID. Errors: invalid evidence, conflict, forbidden. Idempotent by offer/observation/action. Invokes `ProviderOffer.Discover`, `ConfirmListing` or `RecordWithdrawal`. Withdrawal requires confirmed removal according to source policy, not one broken response.
- `recover_job(job_id, expired_token)` and `reenter_job(job_id, new_input_hash, parser_version)`: Collector coordinator; service identity; expired lease or changed input/parser required. Response job ID/state/reconciliation fact ID. Errors stale lease, conflict, invalid request. Idempotent by expired token or new work tuple. Invokes lease-expiry reconciliation or `CollectionJob.Enqueue`. Infrastructure transitions persist lease facts and the job attempt counter and write no attempt row; no domain event because dependencies are not released.
- `retire_snapshot(content_hash, successor_hash, publication_id)`: Publisher; service identity; successor publication on same channel required. Response retirement fact ID. Errors conflict, invalid evidence, forbidden. Idempotent by old hash/publication ID. Invokes `RoutingSnapshot.Retire` automatically after SnapshotPublished.
- `compile_snapshot(input_manifest, schema_version, policy_version, calibration_version, identity_authority_version, identity_freshness_version, comparison_policy_versions, knowledge_cutoff, distribution_class)`: Publisher service identity; read approved projections and write staging only. `distribution_class` is `local` or `distributable` and is pinned into the compiled artifact. Every input requires current non-conflicting allowed research/extraction permissions; `distributable` additionally requires redistribution permission on every included input. Missing/expired/unknown permissions exclude inputs. Response content hash, artifact locator and coverage digest. Errors: invalid evidence, schema incompatible, temporarily unavailable. Idempotent by ordered manifest, all pinned versions and knowledge cutoff. Response artifact retains identity resolution status/cutoffs/evidence and benchmark raw/comparison/calibration eligibility separately. Invokes `RoutingSnapshot.Compile` through the `EvidenceProjection` domain service, which owns cross-aggregate evidence/rights reconciliation.
- `validate_snapshot(content_hash, validator_version)`: Independent validation port under publisher service identity; immutable staging artifact only. Response validation fact with outcome and safe findings. Errors: invalid evidence, schema incompatible, snapshot unavailable. Idempotent by content hash/validator version. Invokes `RoutingSnapshot.Validate`; no publication on failed outcome.
- `publish_snapshot(content_hash, channel, channel_class)`: Publisher; owning service identity; successful validation for the same hash. `channel` names the publication lane; `channel_class` is `local` or `distributable`. A local-class artifact may publish only to local channels; a distributable-class artifact may publish to either. The rights gate is re-evaluated inside the publication transaction against the artifact's pinned distribution class and current source policies: a revocation committed before insertion fails the gate; one committed after leaves the published artifact intact and excludes successor compiles. Response publication ID and artifact locator. Errors: forbidden, invalid evidence, snapshot unavailable, conflict. Idempotent by content hash/channel; same hash and channel with a different channel class conflicts. Invokes `RoutingSnapshot.Publish`.
- `route(RouteRequest)`: Host adapter; trusted local invocation; may select only eligible offers under loaded policy. Response `RoutingDecision`. Errors: invalid request, schema incompatible, snapshot unavailable, stale required fact, no admissible offer or budget exceeded. Pure/idempotent for request values, snapshot hash and runtime generation; no persistence or event side effect. Invokes `Route` domain service, not an invented mutable routing aggregate.
- `adopt_snapshot(artifact_bytes, expected_schema)`: Host adapter; local file-read authority; hash/integrity/schema/freshness validation. Response active content hash or retained prior hash with rejection reason. Errors: invalid evidence, schema incompatible, snapshot unavailable. Idempotent by artifact hash; atomic swap. Local infrastructure operation, not a Knowledge aggregate transition. Remote signatures are not assumed.
- `record_receipt(HostReceipt)`: Host outcome reporter; local host identity; eligible receipt source. Response receipt ID/observation ID. Errors: invalid request, conflict, forbidden. Idempotent by receipt ID with exact-body hash; same ID/different bytes conflicts. Invokes `HostReceipt.Record` then `SourceObservation.Record` through a host-receipt adapter. Task prompts, images and tool outputs are forbidden payloads by default.

## Domain events

Common envelope: `event_id: string`, `schema_version: positive integer`, `aggregate_id: string`, `occurred_at: UTC timestamp`, `payload_hash: SHA-256` and byte-exact `payload: bytes`. Typed payload fields below are encoded by a versioned boundary serializer, never JSON database columns. Durable transactional outbox, at-least-once delivery, aggregate sequence ordering and consumer deduplication by event ID. Consumers may replay; no global ordering guarantee. Published boundary events require compatible versioned readers.

- `SourcePolicyChanged`: Source, register/revise/disable. Payload source ID/config hash/enabled/permission decisions/parser version. Internal. Coordinator invokes `CollectionJob.Enqueue`; `SourceAdmission` domain service owns enabled/rights/freshness scheduling across source/job aggregates.
- `JobDeferred`: CollectionJob, leased to deferred. Payload job ID/source ID/token/retry deadline/outcome/detail. Internal. Durable retry scheduler reactivates `CollectionJob.Lease` after deadline. Single aggregate reaction, no cross-aggregate domain service.
- `StageOutputRecorded`: SourceObservation, worker output creation plus owned output-to-job link. Payload observation ID/job ID/work-input hash/output ID/source ID. Internal. Coordinator invokes CollectionJob.RecordAttempt/Complete under current lease; `CollectionDependency` owns exact-work validation and durable completion reconciliation. Event and link commit with output; replay cannot release dependencies before JobCompleted.
- `ObservationRecorded`: SourceObservation, immutable creation. Payload observation ID/source ID/URL/body hash/outcome/parser version. Internal. Parser/resolver consume; `EvidenceProjection` owns cross-aggregate validation, identity proposals and offer/revision projections. Duplicate hashes may record observations without reparsing.
- `JobCompleted`: CollectionJob, leased to completed. Payload job ID/token/output ID/stage. Internal. Coordinator releases dependent jobs through `CollectionDependency` domain service. Source observation output is durably committed before completion.
- `RevisionEstablished`: ModelRevision, immutable establishment. Payload revision ID/identity observation ID. Internal, at-least-once ordered outbox delivery. IdentityResolution rechecks pending bindings. ProviderOffer binding lifecycle events and their full payload/consumer contracts are in [temporal identity](model-identity.md#service-and-events). No predecessor benchmark transfer or AliasMembershipRecorded variant remains active.
- `OfferListingChanged`: ProviderOffer, discover/confirm/withdraw. Payload offer ID/observation ID/action/time. Internal. `EvidenceProjection` invalidates affected snapshot inputs. Runtime eligibility remains outside this event.
- `SnapshotCompiled` and `SnapshotValidated`: RoutingSnapshot, compile/validate. Payload content hash/schema/policy/calibration/comparison-policy versions/input-manifest hash; validation variant adds validator version/outcome/findings hash. Internal. Validation worker invokes `RoutingSnapshot.Validate`; successful validation consumer invokes `Publish`. Both reactions are this aggregate's methods.
- `SnapshotPublished`: RoutingSnapshot, validated to published. Payload content hash/schema/policy/calibration/coverage digest/artifact locator. Published to Host Execution. Host snapshot watcher adopts after local integrity checks; no cross-aggregate domain rule, a host infrastructure reaction.
- `SnapshotRetired`: RoutingSnapshot, published to retired when publication channel adopts successor. Payload retired hash/successor hash/publication ID. Internal. `SnapshotRetention` domain service owns cross-snapshot retention and rollback eligibility. Retiring does not delete evidence or forbid local rollback.
- `ReceiptRecorded`: immutable SourceObservation from HostReceipt.Record. Payload receipt ID/observation ID/offer ID/task family/outcome/timestamp. Internal. `OutcomeCalibration` domain service owns cohort/sample/freshness checks before producing successor calibration input. It is not an application coordinator with hidden domain rules.

## Data layer

All future tables use Postgres. Fields are NOT NULL unless a justified nullable column is named; none are currently needed. Exact decimals use `NUMERIC`, times use `TIMESTAMPTZ`, bytes use `BYTEA` and hashes use `BYTEA CHECK(octet_length(...)=32)`. Identity strings are `TEXT`, not ceremonial ID wrapper types. No JSON/JSONB. Enum strings have explicit CHECK constraints matching the domain enums. Primary-key indexes serve key lookups; other indexes below name their queries. Every FK is restrictive unless the child is exclusively owned and intentionally deleted together. Immutable evidence is append-only.

Definitions below enumerate columns, PK, FK, unique/check constraints and query indexes. They are DDL contracts, not migrations.

- `sources`, Source: `id TEXT PK`, `url TEXT UNIQUE`, `source_kind TEXT`, `parser_version TEXT`, `freshness_ceiling_seconds BIGINT CHECK >0`, `enabled BOOLEAN`. CHECK source kind. Index `(enabled,source_kind)` for active source discovery. Policy facts live separately.
- `source_policies`, Source-owned: `source_id TEXT FK sources`, `config_hash BYTEA`, `research TEXT`, `extraction TEXT`, `redistribution TEXT`, `terms_url TEXT`, `license_text TEXT`, `checked_at TIMESTAMPTZ`, `effective_at TIMESTAMPTZ`, `expires_at TIMESTAMPTZ`; PK `(source_id,config_hash)`; CHECK hash/permission enums and effective<expires. Index `(source_id,effective_at DESC)` for current non-expired rights. Same-time conflicting policies fail closed. Historical policies remain immutable.
- `content_blobs`, content store: `hash BYTEA PK`, `bytes BYTEA`; CHECK hash equals SHA-256 bytes at ingestion and publication validation (database hash constraint if the chosen digest extension is enabled). No additional indexes. Independent immutable deduplication, not an aggregate requiring behavior.
- `observations`, SourceObservation: `id TEXT PK`, `source_id TEXT FK sources`, `resource_url TEXT`, `retrieved_at TIMESTAMPTZ`, `http_status INTEGER CHECK BETWEEN 0 AND 599`, `outcome TEXT`, `body_hash BYTEA FK content_blobs`, `headers_bytes BYTEA`, `collector_version TEXT`; CHECK outcome. Index `(source_id,resource_url,retrieved_at DESC)` for latest confirmation and `(body_hash)` for reparsing unchanged evidence. Status zero explicitly denotes no HTTP response.
- `unchanged_observations`, observation-owned: `observation_id TEXT PK FK observations`, `prior_observation_id TEXT FK observations`; CHECK IDs differ. No extra indexes. Validator enforces prior success/same source URL and 304 relation. This join constraint requires the validation gate or a deferred trigger, not a plain row CHECK.
- `assertions`, observation-owned: `id TEXT PK`, `observation_id TEXT FK observations`, `subject_source_id TEXT FK sources`, `subject_upstream_id TEXT`, `locator TEXT`, `verbatim BYTEA`, `parser_version TEXT`, `evidence_class TEXT`, `payload_fingerprint BYTEA`; UNIQUE `(observation_id,subject_source_id,subject_upstream_id,locator,payload_fingerprint)`; CHECK evidence enum/hash. Index `(subject_source_id,subject_upstream_id)` for identity resolution. Each assertion has exactly one subtype child, enforced by deferred validation/trigger before publication.
- `capability_assertions`, Assertion-owned: `assertion_id TEXT PK FK assertions`, `capability TEXT`, `support TEXT`, `operation TEXT`, `direction TEXT`; CHECK all closed enums including input/output/not_applicable and legal modality/tool direction combinations per [image-capabilities](image-capabilities.md#facts-and-admission). Index `(capability,support)` for capability projection; index `(operation,direction,capability,support)` for capability admission. This is the single authoritative definition; image-capabilities.md constrains its combinations without redefining the table.
- `image_format_assertions`, `image_requirement_assertions` and `limit_assertions` are defined exclusively by [image-capabilities](image-capabilities.md#relational-contract), including operation, direction, legal combinations and indexes. Accepted formats are independent facts.
- `claim_assertions`, Assertion-owned: `assertion_id TEXT PK FK assertions`, `dimension TEXT`, `polarity TEXT`, `claim_text TEXT`; CHECK dimension/polarity enums. No extra index; claims displayed by subject.
- Benchmark measurements, runs, period/configuration facts, cohort policies/memberships and sample facts are defined only by [benchmark-comparability](benchmark-comparability.md#relational-contract). Raw measurements may remain unresolved. Do not retain `measurement_assertions` or `configuration_hash` as alternate schemas.
- `price_assertions`, Assertion-owned: `assertion_id TEXT PK FK assertions`, `offer_id TEXT FK offers`, `currency TEXT CHECK length=3`, `amount NUMERIC CHECK >=0`, `unit TEXT`, `category TEXT`, `quote_knowledge TEXT`, `scope_hash BYTEA`; CHECK unit/category/hash/quote-knowledge enums. Index `(currency,category,scope_hash)` for offer quote reconciliation.
- `price_scope_items`, price-owned: `assertion_id TEXT FK price_assertions`, `dimension TEXT`, `knowledge TEXT`, `value_bytes BYTEA`; PK `(assertion_id,dimension)`; CHECK dimension direction/provider/region/service_tier/context_band/cache_retention/operation/width/height/image_count/quality/style/steps; CHECK knowledge known/unknown/not_applicable, non-known cases have empty bytes. Typed band boundary validation is the constructor/publication gate. Dimensions are independent predicates; no derived price duplication. No extra indexes.
- `price_bound_proofs`, price-owned: `assertion_id TEXT FK price_assertions`, `component TEXT`, `covered_range_bytes BYTEA`, `evidence_assertion_id TEXT FK assertions`; PK `(assertion_id,component)`; CHECK finite component category. No extra indexes. Validation requires proof coverage for every applicable component/range before proven-bound admission.
- `assertion_retractions`, Assertion-owned later fact: `assertion_id TEXT FK assertions`, `observation_id TEXT FK observations`, `reason TEXT`, `recorded_at TIMESTAMPTZ`; PK `(assertion_id,observation_id)`. No extra indexes; assertion-live query uses PK.
- `model_revisions`, ModelRevision: `id TEXT PK`, `publisher TEXT`, `revision_name TEXT`, `identity_observation_id TEXT FK observations`, `identity_locator TEXT`; UNIQUE `(identity_observation_id,identity_locator)`. Exact source-evidenced identity is authoritative; publisher/display name alone cannot merge variants. No extra indexes.
- `offers`, ProviderOffer: `id TEXT PK`, `provider TEXT`, `upstream_id TEXT`, `catalog_observation_id TEXT FK observations`, `advertised_kind TEXT`; UNIQUE `(provider,upstream_id)`; CHECK ModelKind. No runtime account fields. No extra indexes.
- `identity_bindings`, `identity_binding_confirmations`, `identity_binding_ends` and `binding_supersessions` are defined exclusively by [model-identity](model-identity.md#relational-contract). No nullable closure columns or latest-observation algorithm is active.
- `offer_listing_facts`, ProviderOffer-owned: `offer_id TEXT FK offers`, `observation_id TEXT FK observations`, `action TEXT`, `observed_at TIMESTAMPTZ`; PK `(offer_id,observation_id,action)`; CHECK action listed/withdrawn. Index `(offer_id,observed_at DESC)` for current listing.
- `coverage_findings`, observation-owned: `observation_id TEXT FK observations`, `subject_upstream_id TEXT`, `channel TEXT`, `outcome TEXT`, `detail TEXT`; PK `(observation_id,subject_upstream_id,channel)`; CHECK outcome researched/empty/blocked/identity_ambiguous/unresearched/invalid. Index `(subject_upstream_id,channel)` for coverage reports. The planned channel inventory is source policy, not inferred from existing scores.
- `jobs`, CollectionJob: `id TEXT PK`, `source_id TEXT FK sources`, `resource_url TEXT`, `stage TEXT`, `input_hash BYTEA`, `parser_version TEXT`, `created_at TIMESTAMPTZ`, `attempts BIGINT CHECK >=0`, `fencing_token BIGINT CHECK >=0`; UNIQUE `(source_id,resource_url,stage,input_hash,parser_version)`; CHECK stage/hash. Index `(source_id,stage,created_at)` for work selection. Attempts/token are mutable aggregate counters maintained atomically.
- `job_leases`, CollectionJob-owned: `job_id TEXT FK jobs`, `token BIGINT CHECK >0`, `worker_id TEXT`, `leased_at TIMESTAMPTZ`, `expires_at TIMESTAMPTZ`; PK `(job_id,token)`; CHECK expires>leased. Index `(expires_at)` for lease recovery. Current token on the locked job row prevents two active acknowledgements.
- `job_attempts`, CollectionJob-owned: `job_id TEXT FK jobs`, `token BIGINT`, `observed_at TIMESTAMPTZ`, `outcome TEXT`, `detail TEXT`, `retry_not_before TIMESTAMPTZ`; PK `(job_id,token,observed_at)`; FK `(job_id,token)` to leases; CHECK classified outcome. Index `(retry_not_before,outcome)` for retry deadlines. Retry-not-before is an actual attempt decision even for terminal outcomes, not a hypothetical completion fact.
- `job_completions`, CollectionJob-owned: `job_id TEXT PK FK jobs`, `token BIGINT`, `output_id TEXT`, `completed_at TIMESTAMPTZ`; FK `(job_id,token)` to leases. Output refers to the named stage's typed output through validation, not a nullable FK bag. No extra indexes.
- `snapshots`, RoutingSnapshot: `content_hash BYTEA PK`, `schema_version INTEGER CHECK >0`, `policy_version TEXT`, `calibration_version TEXT`, `created_at TIMESTAMPTZ`, `knowledge_cutoff TIMESTAMPTZ`, `identity_authority_version TEXT FK identity_authority_policies`, `identity_freshness_version TEXT FK identity_freshness_policies`, `projection_bytes BYTEA`, `coverage_digest BYTEA`; CHECK hashes. Index `(created_at DESC)` for retention. Intentional denormalization: immutable materialized projection is the low-latency artifact and is reproducible from its manifest.
- `snapshot_comparison_policies`, Snapshot-owned: `snapshot_hash BYTEA FK snapshots`, `policy_version TEXT FK benchmark_cohort_policies`; PK `(snapshot_hash,policy_version)`. No extra indexes; PK serves pinned comparison policy lookup.
- `snapshot_inputs`, Snapshot-owned: `snapshot_hash BYTEA FK snapshots`, `ordinal INTEGER CHECK >=0`, `observation_id TEXT FK observations`; PK `(snapshot_hash,ordinal)`; UNIQUE `(snapshot_hash,observation_id)`. No extra indexes.
- `snapshot_validations`, Snapshot-owned: `snapshot_hash BYTEA FK snapshots`, `validator_version TEXT`, `outcome TEXT`, `findings_bytes BYTEA`, `validated_at TIMESTAMPTZ`; PK `(snapshot_hash,validator_version)`; CHECK outcome accepted/rejected. No extra indexes.
- `snapshot_publications`, Snapshot-owned: `id TEXT PK`, `snapshot_hash BYTEA FK snapshots`, `channel TEXT`, `channel_class TEXT CHECK IN ('local','distributable')`, `artifact_locator TEXT`, `published_at TIMESTAMPTZ`; UNIQUE `(snapshot_hash,channel)`; index `(channel,published_at DESC)` for active publication. Validator/rights cross-row gate requires transaction-level validation before insertion.
- `stage_output_links`, SourceObservation-owned: `observation_id TEXT FK observations`, `job_id TEXT FK jobs`, `work_input_hash BYTEA`, `output_id TEXT`, `recorded_at TIMESTAMPTZ`; PK `(job_id,observation_id,output_id)`; CHECK hash. Index `(job_id)` for output-without-completion crash reconciliation. Inserted with output event.
- `snapshot_retirements`, Snapshot-owned: `snapshot_hash BYTEA FK snapshots`, `successor_hash BYTEA FK snapshots`, `publication_id TEXT FK snapshot_publications`, `retired_at TIMESTAMPTZ`; PK `(snapshot_hash,publication_id)`; CHECK hashes differ. No extra indexes.
- `outbox_events`, emitting aggregate transaction: `event_id TEXT PK`, `aggregate_id TEXT`, `aggregate_sequence BIGINT CHECK >0`, `event_name TEXT`, `schema_version INTEGER CHECK >0`, `occurred_at TIMESTAMPTZ`, `payload_hash BYTEA`, `payload BYTEA`; UNIQUE `(aggregate_id,aggregate_sequence)`; CHECK event names/hash. Index `(occurred_at,event_id)` for delivery scan. Intentional immutable byte payload for versioned transport; query-relevant envelope columns stay relational.
- `consumer_receipts`, delivery infrastructure: `consumer_id TEXT`, `event_id TEXT FK outbox_events`, `received_at TIMESTAMPTZ`; PK `(consumer_id,event_id)`. No extra indexes. Producer sequence provides ordering, consumer receipts deduplication.

Host receipts are stored as byte-exact observations and parsed into typed assertions. A separately queryable task-success outcome relation is required before calibration is implemented; its validator vocabulary, privacy retention and typed usage variants remain open. Likewise benchmark/task calibration and runtime policy persistence need contracts once their empirical design is chosen. They cannot be implemented from an opaque payload placeholder.

All authority relations are intended to be 5NF. Recorded exceptions are snapshots and event transport payloads. Source rights policies and typed configuration validation remain explicit gate work, not implied completed constraints. Migrations must instantiate the declared FK/CHECK/unique constraints and add triggers where cross-row invariant enforcement is required.

## Cross-check gate

Source registration/policy change maps to source methods, SourcePolicyChanged and source/policy rows. Job enqueue/lease/attempt/defer/complete maps to job ports and lease/attempt/completion facts; enqueue and lease have no domain publication because they are infrastructure coordination, while defer/complete have durable events. Observation creation maps to recording port, ObservationRecorded and observation/assertion/coverage rows. Revision establishment and ProviderOffer binding/confirmation/end/supersession/listing transitions map to their authoritative ports, events and fact tables. Alias lookup is an offer lookup, not a competing lifecycle. Benchmark raw capture uses observation ports/events and typed run/measurement children; read-only comparison classification has no domain event by design. Snapshot compile/validate/publish/retire maps to snapshot ports, events and snapshot fact tables; retirement is an automatic publication-channel reaction, not a user button. Pure route has no event/table by design. Host adoption has no Knowledge aggregate transition by design. Receipts enter as observations; calibration is forbidden until its remaining data contract is complete.

Before code: settle source rights and task outcome vocabulary; add exact calibration/policy tables; instantiate schema; validate every sum-type completeness rule and cross-row invariant; replay event sequences against real Postgres. This draft is not a declaration that the three-contract gate has passed.
