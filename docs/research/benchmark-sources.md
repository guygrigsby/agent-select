# Benchmark sources (extraction record)

This document records only what was recoverable from the fetched source bytes. It intentionally contains no speculative scores or rankings. The URL-to-file audit trail is `data/source-manifest.tsv`; raw responses are in `data/research/benchmark-sources/`.

## Collection policy

Use deterministic, versioned tables first. A collector must preserve source URL, retrieval time, HTTP result, content hash, benchmark revision, model/provider identity, modality, split, prompt/configuration, harness/scaffold, sample count and units. Missing is not zero and is not a negative result. Capability labels are separate from benchmark strength. Vendor-reported and independent evaluations are separate. Effort, scaffold, agent policy and harness are not model attributes.

Unstructured HTML is secondary: run only on change detection; retain quoted evidence, numeric parsing checks, exact identity checks and schema validation; quarantine failures for review. Do not continuously scrape, guess undocumented endpoints, or redistribute data where permission is unclear. Unknown future revisions remain unresearched.

## Collector contract

1. Resolve URL-to-file from the saved log, never from memory; hash and archive bytes.
2. Detect revisions using ETag/Last-Modified or content hash, subject to documented access and rate limits.
3. Parse structured tables before HTML. Require schema, exact identity, release/split and configuration; reject mixed verified/pro, standard/plus, or benchmark revisions.
4. Store vendor-reported, independent, preference, and harness/agent results in distinct namespaces.
5. On parse or identity failure, preserve quoted evidence and quarantine; emit missing rather than zero. Review only change-triggered quarantines.
